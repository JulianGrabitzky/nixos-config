# nixos-config

Personal NixOS flake with one folder per host, shared defaults in `common/`, and optional desktop/service profiles that can be mixed into each machine.

## Structure

`flake.nix`
: Declares inputs and exposes `nixosConfigurations`.

`common/default.nix`
: Shared settings applied to every host, such as locale, keyboard layout, and baseline packages.

`hosts/<name>/default.nix`
: The entrypoint for a machine. It imports shared config, picks service and desktop profiles, and defines host-specific boot/network/user settings.

`hosts/<name>/hardware-configuration.nix`
: Hardware-specific config generated by NixOS.

`hosts/<name>/home.nix`
: Home Manager config for the single user on that machine.

`desktops/*.nix`
: Swappable desktop environment profiles.

`services/*.nix`
: Optional feature bundles that can be enabled per host.

## Working On The Config

When adding new files that are imported by the flake, stage or commit them before running flake-based commands. Git flakes ignore untracked files.

Check the config without building:

```bash
nix flake check --no-build
```

Build the `velkhana` system without switching:

```bash
sudo nixos-rebuild build --flake .#velkhana
```

Build and switch to the new system:

```bash
sudo nixos-rebuild switch --flake .#velkhana
```

## Trying Niri

The `velkhana` host offers both Plasma and a basic Niri session in SDDM.
After rebuilding, log out and select **Niri** in the login screen's session menu.
To prepare it for the next boot without changing your current work session:

```bash
sudo nixos-rebuild boot --flake .#velkhana
```

Reboot when you are ready to try it. Niri creates an editable configuration at
`~/.config/niri/config.kdl` on first launch. The keyboard layout follows the shared
`eu` layout. Default shortcuts include `Super+T` for Alacritty, `Super+D` for the
Fuzzel app launcher, `Super+Shift+/` for shortcut help, `Super+Alt+L` to lock, and
`Super+Shift+E` to exit. Waybar supplies the status bar and Mako handles notifications.

## Updating Inputs

Update all flake inputs:

```bash
nix flake update
```

After updating, rebuild the host:

```bash
sudo nixos-rebuild switch --flake .#velkhana
```

## Garbage Collection

Delete old system and user generations that are no longer needed:

```bash
sudo nix-collect-garbage -d
```
